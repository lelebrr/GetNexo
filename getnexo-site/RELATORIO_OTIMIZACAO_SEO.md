```json
    "contactType": "customer service",
    "areaServed": "BR",
    "availableLanguage": "pt-BR"
  }
}
```

### WebSite Schema
```json
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "GetNexo",

  }
```


**Exemplos:**
- Automação: "Automação WhatsApp GetNexo - IA para Escalar Vendas | Teste Grátis!"
- Vendas: "Vendas WhatsApp GetNexo - Converse e Venda Mais | Preços"
- CRM: "CRM WhatsApp GetNexo - Gestão de Relacionamento | Teste Grátis!"

### Padrão de Description
```
[Descrição do produto] + [Benefício principal] + [CTA] + [Diferencial]
```

**Exemplos:**
- Automação: "Automação WhatsApp com IA para escalar vendas. Chatbots inteligentes, n8n, Typebot. Teste grátis sem cartão de crédito!"
