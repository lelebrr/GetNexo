# 📊 Benchmark de Competidores

**Origem**: Análises de mercado para posicionamento (Janeiro 2026).
**Objetivo**: Identificar features chave para "roubar" e diferenciar o nosso produto self-hosted.

## 1. Top 10 Ferramentas Similares

| Ferramenta | Foco Principal | Pontos Fortes (para copiar) | Pontos Fracos (para explorar) |
|------------|----------------|-----------------------------|-------------------------------|
| **1. Gorgias** | E-commerce (Shopify) | Integração profunda (carrinho, estoque), IA upsell. | Preço alto. |
| **2. Richpanel** | Self-service (Shopify) | Dashboard lindo, Portal do Cliente (Amazon-style), IA resolve 60%. | Focado muito em Shopify. |
| **3. Tidio** | PMEs | Instalação rápida, Chatbots simples de venda. | Simplista para Enterprise. |
| **4. Intercom** | SaaS & Onboarding | "Series" (fluxos de email/chat), "Fin" (IA), Segmentação. | Preço proibitivo para muitos. |
| **5. Crisp** | All-in-one barato | "Magic Map" (user tracking), CRM simples, UX leve. | Automação limitada. |
| **6. Chatwoot** | Open-source | **Nossa base**. Omnichannel, self-hosted, API aberta, app mobile. | Falta features nativas de venda. |
| **7. Helpscout** | Suporte Humanizado | "Beacon" (preview de produto), Inbox compartilhado limpo. | Pouca automação de venda. |
| **8. Zendesk** | Enterprise | Omnichannel robusto, Answer Bot, Marketplace gigante. | Pesado, caro, difícil de configurar. |
| **9. LiveChat** | Vendas | Templates de venda prontos, integração com e-commerce forte. | Focado em chat síncrono. |
| **10. ManyChat** | Marketing (Whats/Insta) | Fluxos visuais de venda, Botão WhatsApp Pay. | Fraco para suporte técnico (tickets). |

## 2. Diferenciais do Nosso Produto (GetNexo)

1.  **Custo**: Modelo self-hosted + pay-as-you-go é imbatível contra SaaS caros (Intercom/Zendesk).
2.  **Híbrido**: Unimos o suporte técnico do Chatwoot/Zendesk com a agressividade de vendas do Gorgias/ManyChat.
3.  **Privacidade**: "Seus dados, seu container". Apelo forte contra SaaS shared.
4.  **IA Agnóstica**: Cliente escolhe (e paga) o provider que quiser (Gemini, Groq, Local), sem markup escondido abusivo.
