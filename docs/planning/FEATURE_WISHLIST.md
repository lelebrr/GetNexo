# ✨ Feature Wishlist & UX

**Origem**: Ideias de melhoria de UX e funcionalidades comerciais (Janeiro 2026).

## 1. Experiência do Usuário (UX/UI)

-   **Sentiment Analysis (Tom de Voz)**:
    -   IA analisa texto do cliente e pontua de 1 (Puto) a 10 (Empolgado).
    -   Exibe ícone para o atendente: `[Raiva 2]`.
    -   Alerta: Se subir para 9 (Muito satisfeito), sugere café/brinde.
    -   Relatório: "Tom inicial x Tom final" para medir eficácia do suporte.
-   **Magic Map (Rastreamento)**:
    -   Mostra onde o cliente está na tela (scroll, cliques) em tempo real.
    -   "Cliente está olhando a página do notebook há 2 min".
-   **Beacon com Preview**:
    -   Chat flutuante já mostra o produto que o cliente está vendo.
    -   Link direto para "Troca" se detectar palavra "quebrou".

## 2. Ferramentas de Venda

-   **Series (Automação)**:
    -   Sequência de mensagens multicanal (Email + WhatsApp).
    -   Ex: Perguntou frete -> Não comprou -> Manda cupom no Whats 1h depois.
-   **Templates de Venda**:
    -   Fluxos prontos para ativar: Abandono de Carrinho, Upsell, Cross-sell, Win-back.
-   **Magic Replies**:
    -   Sugestão de resposta rápida com dados reais do ERP (Bling/VTEX).
    -   Cliente fala "caro" -> Sugere: Parcelamento, Cupom 5%, Frete Grátis.
-   **WhatsApp Pay**:
    -   Botão nativo de pagamento no balão do chat.
    -   Copia chave Pix direto.
-   **Behavioral Tagging**:
    -   Tag auto: "Interesse Alto" (Vi product X 3 vezes).
    -   Disparo de oferta baseado na tag.

## 3. Funcionalidades de Suporte

-   **Answer Bot Rico**:
    -   Responde com link direto, imagem e botão de ação, não só texto.
-   **Portal Self-Service**:
    -   FAQ interativo com busca por voz.
    -   Vídeos tutoriais embarcados.
-   **Colaboração Real-time**:
    -   Dois atendentes no mesmo ticket.
    -   Comentários internos com `@menção`.
-   **Voice-to-Ticket**:
    -   Cliente manda áudio no Whats -> Transcreve -> Abre Ticket.
    -   (Já temos TTS, falta STT cliente -> sistema).

## 4. Gestão & Revenda

-   **Dashboard Revenda**:
    -   Parceiro vê apenas os clientes dele.
    -   Relatório de receita separado.
-   **Relatório de Churn**:
    -   Quem parou de comprar após abrir suporte?
-   **Onboarding Guiado**:
    -   "Primeira vez aqui?" -> Seta guiando no chat.
-   **SLA por Produto**:
    -   Notebook (4h) vs Celular (24h).
    -   Ticket muda de cor conforme prazo.
-   **Botão "Reportar Bug"**:
    -   No painel admin/cliente.
    -   Form simples + Gravação de tela automática (browserless) + Logs.
