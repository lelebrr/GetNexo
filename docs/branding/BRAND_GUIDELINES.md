# Documento de Marca USE NEXO / GETNEXO
**Versão 2.0 (Dark Futurist) – 17/01/2026**

## 1. Conceito Visual: "Dark Futurist"
Uma estética de "Centro de Comando Cyberpunk". Não é um site institucional; é uma máquina de guerra comercial.
*   **Atmosfera**: Hacker de elite, cockpit de caça, terminal de dados.
*   **Sensação**: Velocidade (0ms), Controle Total, Lucro Imediato.

## 2. Tipografia (A Voz da Máquina)

*   **Principal (Corpo)**: **Inter** (Variable).
    *   *Uso*: Textos corridos, botões, UI geral. Leiturabilidade máxima em fundo preto.
*   **Código/Dados**: **JetBrains Mono**.
    *   *Uso*: H1, H2, Números (Preços, ROI), Logs, Status. Reforça o aspecto técnico.

## 3. Paleta de Cores (Psicologia Neural)

| Cor | Hex | Função Neural |
|-----|-----|---------------|
| **Void Black** | `#000000` | Fundo absoluto (OLED). Foco total no conteúdo. |
| **Urgency Red** | `#FF0033` | Alertas, Erros, "Parar", Escassez ("Restam 3"). Acelera o pulso. |
| **Neon Blue** | `#00F7FF` | Tecnologia, IA, Futuro. Usado em loadings e conexões de dados. |
| **Cyber Gold** | `#FFD500` | Dinheiro, Lucro, Sucesso, CTA Principal. Ouro digital. |
| **Matrix Green**| `#00B2A9` | Confiança, "Go", Operacional. |
| **Text Muted** | `#888888` | Descrições secundárias. Evita fadiga ocular. |

## 4. Elementos de UI

### Glassmorphism (Vidro Tático)
*   **Fundo**: `rgba(5, 5, 5, 0.8)`
*   **Blur**: `backdrop-filter: blur(12px)`
*   **Uso**: Sidebars, Cards flutuantes.

### Neon Glow
*   **Efeito**: `box-shadow: 0 0 15px var(--cor)`
*   **Hover**: O brilho intensifica ao passar o mouse, simulando ativação de energia.

### Scanlines
*   **Efeito**: Linhas horizontais sutis (`background-size: 4px 4px`) em áreas de terminal/logs para textura CRT.

## 5. UX Sensorial (Multissensorial)

O sistema não se limita à visão. Ele usa APIs modernas para engajar outros sentidos.

*   **Haptics (Tato)**: Vibração curta (`navigator.vibrate(50)`) em sucessos/erros.
*   **Audio (Som)**:
    *   *Hover*: Swoosh ultrabaixo.
    *   *Click*: Clique mecânico.
    *   *Sucesso*: Acorde etéreo.
*   **Movimento**: Partículas reativas ao mouse no desktop.
