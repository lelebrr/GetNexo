## 3. ELEMENTOS SUBLIMINARES – AS CURVAS QUE MANIPULAM O OLHO
### A. Curvas Estratégicas – Nunca Retas
No "G" do Get: Curva ascendente no final – "crescimento perpétuo".
Na linha de ECG: Sobrepõe o balão de chat. Termina em curva verde subindo.
Botões: Cantos arredondados 12px – "suave". Hover = glow + escala 1.05.

Por quê? O cérebro odeia ângulos agudos em tech – transmite perigo. Curvas = conforto + fluidez. Curva subindo = lucro subindo.

### B. Glow Neural – Luz Que Respira
box-shadow: 0 0 15px rgba(0, 255, 157, 0.8)
Hover: @keyframes pulse { 0% { box-shadow: 0 0 15px... } 50% { box-shadow: 0 0 25px... } }
Ícones: Glow interno = "IA ligada".

Subliminar: Luz saindo de dentro = "sistema vivo". O olho segue luz. O dedo clica.

### C. Scanlines – Textura de Terminal
background: repeating-linear-gradient(0deg, rgba(255,255,255,0.03), rgba(255,255,255,0.03) 1px, transparent 1px, transparent 4px);
Uso: Fundo de dashboard, painéis admin.
Efeito: Parece tela CRT. "Estou no comando."

### D. Partículas – Onde o Olho Dança
JS: 10 partículas ciano-verde que seguem o mouse.
Mobile: só glow.
Subliminar: Movimento = IA ativa. O visitante sente que algo está processando.

### E. Glassmorphism – Vidro Tático

Uso: Cards, sidebar, painéis.
