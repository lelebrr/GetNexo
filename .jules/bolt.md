## 2026-04-08 - SQLite Conditional Aggregation Fallback
**Learning:** When using conditional aggregation (`SUM(CASE WHEN...)`) in SQLite via `better-sqlite3` to consolidate multiple `SELECT COUNT(*)` queries, if the table is entirely empty, the `SUM` function returns `null` instead of `0`. This can cause runtime errors if downstream code strictly expects a numeric value or accesses properties on a null object.
**Action:** Always provide robust fallbacks both at the SQL level (using `COALESCE` or default objects if `.get()` returns null) and at the JavaScript variable assignment level (e.g., `value || 0`) when replacing `COUNT` with `SUM(CASE WHEN...)`.
