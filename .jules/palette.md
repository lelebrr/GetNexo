## 2024-05-30 - Screen Reader & Keyboard Navigation Improvements
**Learning:** Raw text symbols (like '←' and '✕') used as icons in UI components must be explicitly hidden from screen readers using `aria-hidden="true"`, as screen readers often announce them literally, creating confusion. Additionally, custom icon-only buttons often lack default visible keyboard focus states, making keyboard navigation difficult or impossible for sighted users relying on tabs.
**Action:** When implementing or fixing icon-only buttons, especially those using raw text symbols, ensure the symbol itself is wrapped in an element with `aria-hidden="true"`, provide an explicitly descriptive `aria-label` on the parent button, and always apply visible focus state utility classes like `focus-visible:ring-2 focus-visible:outline-none rounded` to guarantee keyboard accessibility.
