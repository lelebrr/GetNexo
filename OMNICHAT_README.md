# ⚡ OmniChat v1.4 - Zendesk Edition

A versão definitiva com **features de Enterprise**.

## 🌟 Novidades v1.4 (Zendesk Style)
- **⚡ Macros (Respostas Rápidas)**:
  - Digite `/` no chat e escolha uma resposta pronta.
  - Cadastre novas macros via API ou banco.
- **🔒 Notas Internas (Sussurro)**:
  - Ative o modo "Nota Interna". O fundo fica amarelo.
  - Mensagens são salvas mas **nunca enviadas** ao cliente. ideal para instruir a equipe.
- **🤖 Treinamento de AI**:
  - Nova aba **AI**. Escreva o "sobre" da sua empresa e clique em salvar.
  - O sistema guarda esse contexto para usar nas respostas automáticas.

## 📦 Como Instalar
1. `tar -xzvf omnichat-v1.4.tar.gz`
2. `docker compose up -d`
3. Acesse `http://localhost:8080/dashboard/chat`
